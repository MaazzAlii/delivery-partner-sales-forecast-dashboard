# CaremEats Partner Analytics — Next.js Predictive Dashboard

Predictive sales and order volume forecasting web application for small Careem NOW restaurant partners.

## Educational Disclaimer
> **SYNTHETIC DATA DISCLAIMER**: All numbers, metrics, order volumes, pricing, and revenue figures displayed in this application are **100% synthetic and simulated**. They do not represent actual financial, operational, or business data from Careem NOW, Careem Technologies, or any affiliated merchant partners. This project was developed strictly for educational and portfolio demonstration purposes as part of the SafeX Solutions Internship (Week 4, Group 56).

## Local Development Setup

### Prerequisites
- Node.js 18.x or later
- npm or pnpm

### Running Locally

```bash
# Navigate to the dashboard directory
cd dashboard

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Build & Production Test

```bash
npm run build
npm run start
```
