# Prompt 18 — Draft Outreach Messages (drafts only — I send these manually)

---

Read `.agent.md` and `docs/target_organizations.md` first.

For each real organization identified in Prompt 17, draft one short outreach
message in `docs/outreach_drafts.md`. Each message must:
- Clearly state I'm a SafeX Solutions intern (Group 56, Week 4 AI/ML project).
- Briefly state why I'm reaching out (built a forecasting dashboard relevant to
  their kind of business, would value their perspective).
- Offer a no-obligation, short intro call — not a sales pitch, not a demand.
- Be honest — no exaggerated claims about the dashboard or fake urgency.
- End with a clear, easy way to say no ("No worries at all if this isn't useful
  to you right now").
- Be personalized per organization (reference what they actually do), not a
  templated mail-merge block.

Explicitly label the file: "DRAFTS FOR MANUAL REVIEW AND SENDING — do not auto-send."
Do not write or suggest a bulk-send script for these.

Commit as `docs(outreach): draft personalized outreach messages` and push.
Update `.agent.md`, set next prompt to `prompts/19-outreach-tracker-log-template.md`, commit, push.
